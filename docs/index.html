The idea

Three things you will never type again

Every NAS session used to start the same way. Neat NAS keeps all three, safely, and skips straight to your files.

192.168.1.126

The address

Was it .126 or .128? Neat NAS finds your NAS on the network and remembers it. It even survives a router reboot, because it can look the NAS up by name.

admin

The user name

Saved with the NAS, shown in the sidebar, editable in one click when the family account changes.

••••••••••

The password

Stored in the macOS Keychain or Windows Credential Manager, never in a text file. Neat NAS asks for it once and never shows it again.

Everything you need, nothing you don't

A file browser that treats your NAS like a folder that is always there

Opens on your files

The last NAS you used is connected before the window finishes appearing.

Finds your NAS itself

Synology, QNAP, TrueNAS or a Raspberry Pi: anything announcing SMB on the network appears in the add dialog.

Quick Look for everything

Photos, video, audio, PDF and text stream straight from the NAS. Press Space, like in Finder.

Move files both ways

Download or upload files and folders, drag out into Finder, drop in to upload.

Transfers that survive

Paused or interrupted transfers pick up where they stopped, even after you quit the app.

Instant photo grids

Thumbnails use the previews cameras embed in every photo, so RAW and HEIC folders need only the file headers.

Ten languages, two themes

Light and dark follow the system. The UI speaks English, Chinese, Japanese, Korean, German, Spanish, French, Portuguese and Russian.

Updates itself, safely

New versions show up in Settings and install in one click, verified with a signature before anything runs.

Built light

Native core, system web view, no Electron

Neat NAS speaks SMB 2 and 3 through a pure-Rust client and draws its interface in the web view your OS already ships. Nothing is mounted and nothing needs admin rights.

Getting started

Set up once, in under a minute

Install

Open the .dmg on macOS or run the installer on Windows. No admin rights needed.

Pick your NAS

It is usually already listed. Enter the user name and password once; they go to the keychain.

That's it

From now on, opening Neat NAS means opening your files.
